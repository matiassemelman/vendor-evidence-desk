# How I built this with AI

1. I started from a real product boundary: AI prepares evidence; a person owns the consequential decision.
2. Codex helped turn that boundary into a synthetic case, an observable demo path, and explicit non-goals before code.
3. The first implementation grew to roughly 4,200 executable lines while protecting hypothetical infrastructure more than the portfolio claim.
4. I stopped it instead of polishing sunk cost.
5. We preserved the product contract and fixtures, discarded the architecture and code, and rebuilt under a hard 500-line budget.
6. For each material area we checked at most two current primary references, then recorded `practice → decision → omitted`.
7. The rebuild uses one Next.js app, one structured model call, deterministic evidence checks, one human gate, one table, five tests, and five evals.
8. A labeled replay keeps the product inspectable without misrepresenting a live model run.
9. Watching the deployed flow exposed a UX failure: the action completed below the viewport with no visible handoff.
10. I raised the ceiling to 1,000 only for visible product quality: guided progress, honest loading, focus management, a result summary, and explicit handoffs. The result uses 840 lines.
11. A second observed ambiguity led to a compact run trace that distinguishes model proposals, deterministic checks, replay and human authority. The result remains under 900 lines.
12. One technical review and at most one corrective pass prevent both AI slop and review-driven scope inflation.
13. I remain responsible for scope, credentials, spend, deployment, and every public claim; commits, tests, eval reports, and the visible demo are the evidence.
