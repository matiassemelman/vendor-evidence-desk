# Architecture glossary

- **Case Lab:** guided public surface for running and inspecting the fixed case.
- **Synthetic packet:** the three fictional documents owned by the server.
- **Document worker:** one bounded analyzer that sees one untrusted document.
- **Evidence gate:** exact schema, document and excerpt validation before reduction.
- **Deterministic reducer:** code that merges facts and derives the terminal route.
- **Human gate:** the only authority that resolves the consequential bank conflict.
- **Revision:** immutable analysis plus a separately changing lifecycle.
- **Successor:** a new current revision created after an allowlisted document change.
- **Mock export receipt:** idempotent record of the approved revision, not a real ERP call.
- **Replay:** versioned fixture explicitly labeled as zero live provider calls.
- **Evaluation suite:** five fixed live regression cases and deterministic assertions.
- **Calibrated judge:** one secondary qualitative model check guarded by two anchors.
